# HomeFit — домашние тренировки

iOS-приложение (Expo / React Native, TypeScript) для тренировок дома по персональному плану.

- **Анкета**: пол (необязательно), возраст, рост, вес, цель (сила/мышцы, тонус, общая форма), максимум отжиманий и подтягиваний, турник, инвентарь (гантели с весом и типом, штанга с рабочим весом, резинки, скамья/стул).
- **Дни тренировок**: 2–6 дней в неделю, рекомендация «3 раза через день (Пн/Ср/Пт)» выбирается одним нажатием.
- **Генератор плана** (`src/lib/planGenerator.ts`): чистый детерминированный TypeScript, без сети и ИИ. Определяет уровень, подбирает базовые упражнения под инвентарь, делит по дням (2–3 дня — всё тело A/B/A, 4 — верх/низ, 5 — верх/низ + всё тело, 6 — жимы/тяги/ноги), задаёт подходы, повторы, отдых и стартовый вес.
- **Экраны**: «Сегодня» (отметка подходов + таймер отдыха), «План» (неделя), «Упражнения» (поиск и фильтр по инвентарю), карточка упражнения (2 фото: старт/финиш, техника, ошибки), «Прогресс» (журнал и статистика), «Профиль» (правка данных → новый план), «О приложении».
- **Данные** хранятся только на устройстве (AsyncStorage + zustand). Светлая и тёмная темы.

## Запуск

```bash
npm install
npx expo start
```

Отсканируйте QR-код камерой iPhone — проект откроется в **Expo Go** (нужна версия Expo Go для SDK 54).

Проверки:

```bash
npx tsc --noEmit                    # типы
npm test                            # unit-тесты генератора (jest-expo)
npx expo-doctor                     # совместимость зависимостей
npx expo export --platform ios      # сборка JS-бандла
```

Эти же шаги выполняет GitHub Actions (`.github/workflows/ci.yml`) на каждый push.

## Сборка и публикация в App Store (без Mac)

```bash
npm install -g eas-cli
eas login
eas build -p ios --profile production   # облачная сборка на серверах Expo
eas submit -p ios                       # отправка в App Store Connect
```

Нужен аккаунт Apple Developer. При первой сборке EAS сам создаст сертификаты и профили.
Bundle ID: `com.deckkk491.homefit`. Профили сборки — в `eas.json` (development / preview / production).

## Структура

```
app/                    экраны (expo-router)
  (tabs)/               Сегодня, План, Упражнения, Прогресс, Профиль
  exercise/[id].tsx     карточка упражнения
  disclaimer.tsx        предупреждение о здоровье
  onboarding.tsx        анкета
  about.tsx             О приложении
src/lib/planGenerator.ts  генератор плана
src/data/exercises.ts     библиотека упражнений (61 шт.)
src/data/exerciseImages.ts карта фото (генерируется)
src/store/                состояние + AsyncStorage
assets/exercises/         фото упражнений
scripts/                  генерация иконки и карты фото
__tests__/                тесты
```

Иконка и сплэш рисуются скриптом `python3 scripts/generate-assets.py` (Pillow), карта фото — `node scripts/generate-image-map.js`.
